# CSP451 CheckPoint 1 Static Site

## Description
This project demonstrates the basics of Git, GitHub, version control, and a simple static website. It includes HTML, CSS, JavaScript, Markdown documentation, and Git workflow practice.

## Installation

### Prerequisites
- Git installed
- GitHub account
- GitHub CLI installed
- Web browser

### Steps
```bash
git clone https://github.com/farhanzamir7/CSP451-CheckPoint1-FarhanZamir.git
cd CSP451-CheckPoint1-FarhanZamir
```

## Usage
Open `index.html` in a browser to view the website.

Helpful Git commands:

```bash
git status
git log --oneline
git branch
git checkout -b feature/add-about-page
```

## Contributing
Use a feature branch workflow.

Commit messages should follow Conventional Commits:

```bash
feat: add new page
docs: update README
style: improve formatting
fix: correct broken link
refactor: restructure code
```
